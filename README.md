# 译包 LangPack · 多平台真实翻译

**[在线体验：译包 LangPack · 多语言工作台](https://langpack-standalone.406859116.workers.dev/)**（Cloudflare Workers 独立部署）

完整体验：项目首页 → 文本输入 / 文档导入 → 多选语言 → 选择的平台翻译 → 校对 → JSON / ZIP 下载。

## 打开

前端源码位于 `web/`，服务端代理位于 `worker/`。[在线版本](https://langpack-standalone.406859116.workers.dev/) 已独立部署到 Cloudflare Workers，默认可直接使用 MyMemory；使用其他平台时，在偏好设置中填写自己的凭据。

本地运行 `node scripts/dev-server.mjs`，可通过标准输入的一行 JSON 提供开发者专用配置（`{"key":"你的服务端密钥","developerToken":"至少24个字符的随机开发者口令"}`），或通过受控环境提供 `TRANSLATION_API_KEY` 与 `LANGPACK_DEVELOPER_TOKEN`。未配置开发者口令时，服务器共享密钥不可调用；用户自备平台密钥不依赖此配置。访问打印的 `http://127.0.0.1:4173`。不要把密钥放进命令行参数、前端代码或交付包。

构建执行 `bash scripts/build.sh`，再执行 `node scripts/validate-artifact.mjs`；生成的 `dist/server/index.js` 内嵌静态界面，但不包含运行时密钥。

## GitHub Actions 手动打包与发布

打开 [Manual packages and release](https://github.com/CherryIce/langpack-prototype/actions/workflows/manual-packages.yml)，点击 **Run workflow**，选择分支，再勾选需要的 **APK / Web / macOS / Windows**，支持同时选择多个平台。默认只选 APK；必须至少选择一个平台。工作流会先执行 Flutter 静态检查和测试，然后只构建勾选的平台，不调用真实翻译接口。

| 平台 | 下载内容 |
| --- | --- |
| APK | 可安装的 Debug 签名 `.apk`，供测试使用 |
| Web | Release 静态网站 ZIP；完整平台代理仍需与网站同源部署 |
| macOS | Release `LangPack.app` ZIP，保留应用包结构；未做开发者签名发布或公证 |
| Windows | Release ZIP，包含 EXE、DLL 和 `data`，请完整解压运行 |

不勾选 **发布到 GitHub Releases** 时，在运行详情的 **Artifacts** 下载产物，保留 14 天。包名包含运行编号与重跑次数，便于对应源码。

需要发布到仓库的 [Releases 页面](https://github.com/CherryIce/langpack-prototype/releases)时，勾选发布选项，并填写一个**尚未使用的版本标签**，例如 `v1.0.0`。所选平台全部成功后，工作流会收集本次运行的包、生成 `SHA256SUMS.txt`，先上传到草稿，再公开 Release。未选择的平台不会阻止发布；构建失败时不发布。已有标签、正式 Release 或草稿均拒绝覆盖，上传中断留下的草稿需自行检查后处理，重新发布请使用新标签。

Release 绑定本次运行的确切源码提交；标签不会改写 `flutter_app/pubspec.yaml` 中的应用版本。APK 仍是测试调试包，macOS 包未公证，此入口不等同应用商店发布。工作流使用 GitHub 自动提供的令牌，仅发布任务拥有仓库内容写权限，不需要把翻译密钥或签名资料加入仓库。

配置位于 [`.github/workflows/manual-packages.yml`](.github/workflows/manual-packages.yml)，发布校验脚本位于 [`scripts/manual-packages.mjs`](scripts/manual-packages.mjs)。原有 `Flutter multiplatform` 检查流程保留。

## 已实现

- 项目创建、搜索、文案列表和浏览器本地保存。
- 文本按行 / 空行拆分，常见文案语义 key；自定义内容使用稳定备用 key，并允许手动命名。
- TXT、Markdown、DOCX 本地解析，段落勾选、编辑、合并与按句拆分。
- 对齐 MediaServiceClient 的 35 种语言资源：简体中文为源语言，另外 34 种可多选为翻译目标，支持按名称或代码搜索。
- 最近目标语言组合保存在本地；开始一次新的批量翻译后，下次新建项目或翻译操作默认沿用，仍可增加、减少或更换语言。
- MyMemory、ZTAITrans、DeepL、Azure、Google、百度翻译、腾讯云、阿里云八个平台；独立凭据、首选平台和启用顺序，记录实际译文来源。仅额度耗尽或不支持精确目标时，按用户启用的顺序使用备用。
- 逐条逐语言进度、暂停与恢复、任务记录和只重试失败项。
- 默认增量翻译：保留当前成功译文，并按同项目完全一致的原文和目标语言复用已有机器译文；重复导入或同批重复文案不再逐条重复请求。
- 长段落按平台限制切分：MyMemory 每段最多 480 UTF-8 字节，新增国内三平台每段最多 1000 码点以兼容百度标准版；合并后仍对应原来的一个 key，保留换行及占位符。
- MyMemory 串行限速约 1.1 秒 / 请求、15 秒超时；其他云平台代理最长等待约 65 秒，ZTAITrans 约 10 分钟，临时网络、限流与服务错误仅有限重试。
- 各平台额度冷却独立，到期后再次尝试首选；普通限流仅有限重试，鉴权或配置错误停止，不借用其他账户的凭据。保留成功结果，不把服务商警告当成译文。
- 译文编辑、人工确认、key 唯一性及占位符检查。
- 独立 JSON 与 ZIP 真实下载，缺失译文阻止正式导出，草稿 ZIP 附校验报告。
- 导出快照重下载、偏好设置、手机底部导航与电脑工作台布局。

用户凭据默认仅当前会话，只有明确选择“本机保存”才单独持久化；不进入项目、任务、导出或浏览器项目备份。本机保存不等于加密保险箱，共享设备不宜使用。删除凭据会同时删除会话及本机副本。切换凭据会使平台请求缓存及配额冷却失效；项目里已经成功的译文仍按原来源增量复用。

保存凭据后会自动进行一次平台验证，保存结果和验证结果分别显示。DeepL 使用只读用量接口、Google 使用语言目录接口，不产生翻译字符用量，成功仅表示对应只读接口的授权检查通过，并非全部语言或后续额度保证。其余平台固定以单个源字符“好”向英语试译一次，可能产生 1 字符用量；匿名 MyMemory 无需验证密钥，也不会发起试译。MyMemory 私有 key 的试译成功不单独证明私有词库权限。

验证不自动重试、不使用备用平台，不写入项目译文或翻译请求缓存；网络故障、超时和限流会提示暂时无法判断，而非误报密钥无效。当前页面内相同凭据仅调整保存方式时复用验证结果，可点击“重新验证”主动检查；刷新或重启后不沿用旧的可用结论。修改或删除凭据会取消、废弃旧验证结果，避免迟到响应覆盖当前状态。验证入口为同源 `POST /api/translation/validate`，只接受平台及凭据，试译内容、目标、接口地址和模型均不允许客户端自定义。

## 边界

MyMemory 匿名/邮箱模式直接请求官方接口；可选私有词库 key 与其他平台一样通过同源 `/api/translation/provider` 转发，不出现在浏览器请求 URL 中。地址、语言映射及模型由服务器固定；Google 固定 NMT，DeepL 免费/标准接口必须显式选择且不会自动升级，ZTAITrans 固定 fast。百度 MD5、腾讯 TC3-HMAC-SHA256、阿里云 RPC HMAC-SHA1 签名均在服务器计算，这三家的签名密钥不会原样发给上游。服务器不保存用户凭据，不返回或记录上游原始错误。旧 `/api/translation/backup` 同样必须通过开发者口令校验，不能绕过新入口继续消耗共享授权。

免费额度由各平台账户结算，本站不查询余额，也不能阻止上游在免费额度用完后直接计费；需要在平台控制台限制预算或关闭后付费。阿里云 `10013` 同时可能表示未开通或欠费，因此按配置错误停止，不当作免费额度用尽自动消耗备用。百度同一代理出口 IP 当日使用多个 APP ID 可能触发 `58003` 访问限制，该错误也会停止并提示检查，不自动切换平台。

点击开始翻译会将所选原文发送给相应服务；文档文件本身只在本地解析，不调用公共翻译记忆写入接口。设置中可选填自己的有效联系邮箱，通过 `de` 参数随请求发送。官方匿名额度每天 5,000 字符，提供有效邮箱为每天 50,000 字符，具体以服务商规则为准。

key 继续由本地规则生成，未知文案提供稳定备用 key 并允许手动命名。未接入语义命名大模型、账户或云端存储。数据保存在当前浏览器，清理站点数据后不会保留；导出记录最多保留最近 20 次。

旧项目、人工编辑和导出快照保留。旧版未编辑的演示译文会标记来源，并要求重译或重新人工确认，不会冒充真实服务结果。批量翻译默认保护人工修改和已确认内容；单条重译提供明确替换操作，并防止迟到结果覆盖请求期间的新编辑。

## 增量翻译

网页版与 Flutter 版默认只处理新增、原文发生变化或缺少目标语言译文的内容。翻译前会显示待处理、可复用和受保护的译文数量；新增一种语言时，仅补充该语言的缺失项。

复用范围限于当前项目，按原文全文和目标语言精确匹配，不依赖 key。重复导入后，即使生成了新的 key，也能复用已保存在本地的成功机器译文；同一批次的重复原文在首条成功后复用该结果。重启或刷新后，完整成功译文仍可从项目记录中复用。

人工修改及已确认的目标译文受保护。自动复用不选用人工编辑、失败、空白、原文已失效或占位符不一致的候选；同一原文和语言存在不同的有效译文时，不自动替用户选择。复用到新条目的译文保留实际服务来源，并重新等待校对。点击单条“重译”会明确重新请求，不使用增量复用或服务缓存。

本地保存仍是复用的前提；删除项目或清除应用 / 浏览器数据后，对应复用记录不再可用。各版本、设备和浏览器之间不共享译文。

## 目标语言与最近偏好

语言清单对齐 MediaServiceClient 主应用的 `Language-*.json` 资源，包含简体中文源文和以下 34 种目标：繁体中文、英语、巴西葡萄牙语、葡萄牙葡萄牙语、马来语、泰语、法语、西班牙语、阿拉伯语、菲律宾语、越南语、俄语、土耳其语、印度尼西亚语、日语、韩语、德语、印地语、匈牙利语、意大利语、罗马尼亚语、瑞典语、保加利亚语、波兰语、丹麦语、芬兰语、荷兰语、捷克语、斯洛伐克语、乌克兰语、希腊语、书面挪威语、克罗地亚语、僧伽罗语。导出代码沿用对应资源名，例如 `pt-BR` 和 `pt-PT` 分开保存；简体中文直接导出源文，无需调用翻译接口。

MyMemory 没有精确列出巴西葡萄牙语、菲律宾语和书面挪威语，需选择已配置的其他平台。Azure 覆盖全部 34 种；Google NMT 保守排除书面挪威语；DeepL 目录保守排除菲律宾语与僧伽罗语，实际可用性也受账户套餐影响。百度按精确代码支持 32 种（不将通用葡语替代两个葡语地区），部分语种需尊享版；腾讯从中文出发支持 15 种目标；阿里云保守支持 29 种（官方目录未明确支持两个葡语地区、书面挪威语、克罗地亚语及乌克兰语的精确代码）。不会用近似语言或其他地区代码替代，也不会自动借用服务器共享授权。MyMemory 语言参数格式见[官方接口说明](https://mymemory.translated.net/doc/spec.php)，可用语言列表见[官方工作台](https://mymemory.translated.net/)。

最近偏好只在有效的新批量翻译开始时更新，包括全部命中增量复用的任务。只勾选后离开不会覆盖偏好；单条重译、暂停恢复和失败重试不会把上次多选组合缩成单一语言。新项目、新输入 / 导入及新发起的项目翻译默认使用最近组合；校对、导出和重开历史任务保留对应项目或任务的语言快照。旧存档没有最近偏好时继续使用原默认组合，设置中的其他偏好与已有译文不会被清除。

页面关闭会中断网络任务；刷新后成功条目保留，其余项可继续。同一页面会话内，已成功的分段缓存可用于失败重试；刷新后未完整完成的长段落可能重新请求部分分段。原文变化时，旧任务不会覆盖新文案。

文档限制为 10 MB、1000 个内容块；DOCX 需要支持 `DecompressionStream('deflate-raw')` 的现代浏览器。PDF、扫描件和旧版 DOC 暂不支持。复杂 DOCX 布局不保证还原，导出仅包含文本资源。

所有项目文件均为独立新增，未修改上层 APP 效果册。

## 备用服务限制

ZTAITrans 需要用户自己的 API key（可选 tenantId），或开发者访问口令。开发者口令仅用于服务器认证，站点环境密钥始终不发给浏览器。附件文档明确租户月预算，但未提供具体金额或余额查询，不能当作公开免费服务。备用客户端最长等待约 10 分钟，服务端固定 fast，不自动升级档位。单段最多 50,000 个字符、请求体 256 KiB；超过限制需在导入预览中拆分。单条响应实测可能把业务 ID 回显为 "1"，仅在原文完全一致时兼容，其他错配继续拒绝。

仓库与发布包不含实际密钥。开发者共享模式仅在服务端同时配置 `TRANSLATION_API_KEY` 和至少 24 字符的 `LANGPACK_DEVELOPER_TOKEN`，且访问口令验证通过后可用；任一缺失均关闭共享调用。用户 BYOK 缺失或失败不会改用环境密钥。

## Flutter 多端版本

Flutter 工程位于 [`flutter_app/`](flutter_app/README.md)，覆盖 iOS、Android、桌面（Windows / macOS / Linux）与 Web，共用文本输入、文档导入、语言多选、真实翻译、校对与 JSON / ZIP 导出流程。原版 `web/` 和现有服务端代理保留。

使用 Flutter 3.35.7 / Dart 3.9.2，在 `flutter_app/` 执行 `flutter pub get`、`flutter analyze`、`flutter test`。完整 Web 流程先执行 `flutter build web --release`，再到仓库根目录运行 `node scripts/flutter-server.mjs`，打开 `http://127.0.0.1:4180`。原生 App（iOS / Android / Windows / macOS / Linux）本版本默认使用独立站点 `https://langpack-standalone.406859116.workers.dev` 的平台代理；无需自行搭建服务器，但除 MyMemory 外必须配置自己的平台凭据或开发者访问口令。已有空代理地址仍使用该服务。显式自定义的服务器地址仍保留，可在设置中清空以恢复应用默认连接。Flutter Web 使用其部署站点的同源代理；自行部署时，备用密钥仅由运营方通过服务端环境变量 `TRANSLATION_API_KEY` 注入。

Flutter 各端本地数据与原版浏览器数据分别保存，没有账户或云同步；旧版原文需重新导入。平台启动、调试地址、签名、真实 API 验收和 CI 边界详见 [Flutter 使用说明](flutter_app/README.md)。`.github/workflows/flutter.yml` 提供多平台检查；[此前六平台构建记录](https://github.com/CherryIce/langpack-prototype/actions/runs/40858371621) 已成功，后续改动以对应提交的新检查结果为准。构建成功不代表真机验收或商店发布。

已安装的旧版原生 App 可在设置的“备用翻译服务器”中填写 `https://langpack-standalone.406859116.workers.dev`，或安装包含本次默认地址更新的新版本。旧版匿名共享备用已关闭，需更新客户端以使用自备凭据或开发者访问口令；已有项目和有效译文仍可复用。显式自定义地址不会被自动覆盖。各平台费用与额度以自己的账户配置为准。
